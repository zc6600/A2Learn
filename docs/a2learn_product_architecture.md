# A2Learn Product Architecture: Interactive Knowledge Showcase

## 1. Core Product Positioning
A2Learn is not a traditional Learning Management System (LMS). It doesn't require cluttered dashboards or complex control panels.
Its core positioning is an **Interactive Knowledge Showcase** website (akin to an interactive Wikipedia or a digital museum).

Users come here to **explore, browse, and engage in deep interaction with knowledge**. The AI Agent's role is not a supervisor but a **Curator** (Museum Guide), dynamically displaying and expanding knowledge cards based on the user's interests.

## 2. Core Module Planning (Modular Showcase)

The entire website architecture should revolve around "how to display knowledge elegantly and efficiently," divided into the following three showcase modules:

### Module 1: Macro Showcase —— Knowledge Exploration
**Goal**: Allow users to see the global context of knowledge at a glance and explore freely.
- **Dynamic Knowledge Tree**: Displays the hierarchical structure of a discipline in a tree or mind map format. Users can click nodes to expand them layer by layer, rather than reading a dry table of contents.
- **Interactive Tour**: A `LearningPath` generated by the Agent that strings together multiple knowledge nodes into an optimal browsing route, much like a guided museum tour.

### Module 2: Micro Showcase —— Deep Dive Cards
**Goal**: Provide rich, multi-dimensional microscopic displays when a user clicks a specific knowledge point.
- **Concept Detail Card**: A mixed media card containing definitions, historical background, core formulas, or principles.
- **Example Showcase**: If the knowledge point involves programming or engineering, provide expandable code comparison views or interactive sandboxes instead of static code blocks.

### Module 3: Interactive Experience Zone —— Quizzes and Recalls (Interactive Exhibits)
**Goal**: Break the one-way input of "just watching" and introduce "hands-on play" exhibits.
- **Flashcard Deck**: Displays a series of double-sided cards that users can flip to explore the answers behind the questions.
- **Quiz Station**: Displays an interactive quiz card (`QuizCard`). Once the user attempts an answer, the exhibit immediately provides dynamic feedback and principle analysis.

## 3. A2UI Component Mapping

To build this "Knowledge Showcase," we need a set of display fixtures (UI components). Moving away from traditional "task lists" and "progress bars," we focus on designing the following core fixtures:

### 3.1 Macro Showcase Fixtures
- **`LearningPath` [✅ Implemented]**: Horizontal or vertical step-guiding components that clearly show the sequence of learning and current progress, providing a roadmap for the AI.
- **`KnowledgeTree` [✅ Implemented]**: A collapsible tree structure showing the hierarchical relationships of knowledge points (e.g., a course syllabus).
- **`SectionNavigator` [✅ Implemented]**: A non-linear page routing component providing a grid of cards for users to freely choose or unlock different learning chapters, breaking the single-page scroll limitation.

### 3.2 Micro Showcase & Mentoring Fixtures
- **`ScenarioDialogue` [✅ Implemented]**: Enacts knowledge points through multi-character bubble dialogues, supporting paced message display to enhance the immersion of "mentored learning."
- **`ConceptCard` [✅ Implemented]**: Beautifully designed text and image cards supporting large titles, tags, citations, and core definitions.
- **`InteractiveSandbox` [✅ Implemented]**: Inspired by W3Schools. Displays code or concepts on the left and provides a modifiable parameter input or direct code output on the right, allowing users to "Try it Yourself."
- **`ResourceList` [✅ Implemented]**: Provides structured external link displays at the end of a knowledge point (e.g., Wikipedia, official docs, recommended videos).

### 3.3 Interactive Props
- **`Flashcard` [✅ Implemented]**: Cards supporting flip interaction.
- **`QuizCard` [✅ Implemented]**: Supports answering and immediate explanation.
- **`ClozeTest` [✅ Implemented]**: Targets active recall through placeholder filling and immediate feedback to consolidate knowledge.
- **`DragAndDropMatch` [✅ Implemented]**: Enhances practice engagement and memory retention through matching and sorting gameplay.

---

## 4. Summary
A2Learn is a **content-centric, exploration-driven** interactive knowledge showcase. All UI components (such as LearningPath, ConceptCard, Flashcard) are **intelligent exhibits** in this showcase, dynamically generated and pushed to users by the underlying AI Agent for their browsing and interaction.
