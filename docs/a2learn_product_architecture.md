# A2Learn 产品架构设计：互动知识陈列馆 (Interactive Knowledge Showcase)

## 1. 产品核心定位
A2Learn 不是一个传统的“在线教育管理系统(LMS)”，不需要冗杂的个人主页(Dashboard)或控制台。
它的核心定位是一个 **互动式的知识陈列网站**（类似互动维基百科或数字博物馆）。

用户来到这里，是为了**探索、浏览并与知识产生深度交互**。AI Agent 在这里的角色不是监督者，而是**博物馆导览员（Curator）**，根据用户的兴趣，动态陈列和展开知识卡片。

## 2. 核心模块规划 (模块化陈列)

整个网站的架构应该围绕“如何优雅且高效地展示知识”来设计，分为以下三大陈列模块：

### 模块一：宏观陈列 —— 知识图谱与探索 (Knowledge Exploration)
**目标**：让用户一眼看清知识的全局脉络，自由探索。
- **动态知识树 (Knowledge Tree)**：以树状或思维导图的形式陈列学科的层级结构。用户可以点击节点层层展开，而不是看枯燥的目录。
- **互动漫游 (Interactive Tour)**：由 Agent 生成的 `LearningPath` (学习路径)，像导览路线一样，把多个知识节点串联成一条最佳浏览路线。

### 模块二：微观陈列 —— 深度解析卡片 (Deep Dive Showcase)
**目标**：当用户点击某个具体知识点时，提供丰富、立体的微观展示。
- **概念详情卡 (Concept Card)**：包含定义、历史背景、核心公式或原理的图文混排卡片。
- **代码/案例陈列窗 (Example Showcase)**：如果知识点涉及编程或工程，提供可展开的代码对比视图或互动沙盒，而不是死板的代码块。

### 模块三：互动体验区 —— 测验与翻转 (Interactive Exhibits)
**目标**：打破“只看不想”的单向输入，引入“动手玩”的展品。
- **记忆翻转台 (Flashcard Deck)**：陈列一系列带有正反面的卡片，用户可以点击翻转，探索问题背后的答案。
- **即时问答台 (Quiz Station)**：陈列一个互动的测验卡片 (`QuizCard`)，用户尝试解答后，展品立刻给出动态反馈和原理解析。

## 3. A2UI 组件映射

为了搭建这个“知识陈列馆”，我们需要一套展具（UI 组件）。摒弃传统的“任务列表”、“进度条”，我们将专注设计以下核心展具：

### 3.1 宏观陈列展具 (Macro Showcase)
- **`LearningPath` (学习路径) [✅ 已实现]**：水平或垂直的步骤引导组件，清晰展示学习的先后顺序和当前进度，为 AI 提供引导路线图。
- **`KnowledgeTree` (知识树) [✅ 已实现]**：可折叠的树形结构，展示知识点的层级关系（如学科大纲）。
- **`SectionNavigator` (章节导航器) [✅ 已实现]**：非线性的页面路由组件，提供网格卡片让用户自由选择或解锁不同的学习章节，打破“一翻到底”的单页束缚。

### 3.2 微观陈列与导师引导 (Micro Showcase & Mentoring)
- **`ScenarioDialogue` (情景对话模拟器) [✅ 已实现]**：以多角色气泡对话的方式演绎知识点，支持节奏化消息展示，强化“导师陪学”的沉浸感。
- **`ConceptCard` (概念陈列卡) [✅ 已实现]**：设计精美的图文卡片，支持大标题、标签(Tags)、引用和核心释义。
- **`InteractiveSandbox` (互动沙盒) [✅ 已实现]**：借鉴 Web3School / W3Schools 的玩法。左侧展示代码或概念，右侧提供可修改的参数输入框或直接运行的代码输出，用户可以“Try it Yourself”。
- **`ResourceList` (扩展阅读资源) [✅ 已实现]**：在知识点结尾提供结构化的外部链接陈列（如 Wikipedia、官方文档、推荐视频等）。

### 3.3 互动体验展具 (Interactive Props)
- **`Flashcard` (记忆闪卡) [✅ 已实现]**：支持翻转交互的卡片。
- **`QuizCard` (测验卡) [✅ 已实现]**：支持答题与即时解析。
- **`ClozeTest` (互动填空题卡) [✅ 已实现]**：以主动回忆为目标，通过占位符填空+即时反馈巩固知识。
- **`DragAndDropMatch` (拖拽匹配板) [✅ 已实现]**：通过匹配与排序玩法增强练习的参与感与记忆留存。

---

## 4. 总结
A2Learn 是一个**以内容为中心、以探索为驱动**的互动知识陈列馆。所有的 UI 组件（如 LearningPath, ConceptCard, Flashcard）都是这个陈列馆里的**智能展品**，由底层 AI Agent 动态生成并推送到用户面前，供其浏览和互动。
