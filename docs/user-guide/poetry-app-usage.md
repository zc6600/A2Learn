# 诗词赏析 App 使用方式

A2Learn 的诗词模式把“读原文、查词义、看意象、理解情绪、表达自己的判断”组织成一条可交互的阅读路径。它不是把诗词拆成一堆静态知识卡，而是让读者在原文、画面、人物处境和练习之间来回阅读。

本文以张若虚《春江花月夜》和杜甫《登高》为例，说明普通读者如何使用诗词赏析功能。

## 一、开始使用

### 方式 A：直接浏览内置诗词案例

内置案例不需要 API Key，适合第一次体验：

```bash
npm run viewer:dev
```

打开终端显示的本地地址，在页面的“浏览模板案例”中展开“诗词赏析”，然后选择：

- 《春江花月夜》· 词注、月行与两地相望
- 《登高》· 七律之冠与四联镜头解码

也可以直接打开：

```text
http://localhost:5173/?messagesUrl=/examples/poetry-social.json
http://localhost:5173/?messagesUrl=/examples/deng-gao.json
```

### 方式 B：输入自己的诗词主题

需要实时生成时：

1. 点击右上角“设置”，填写自己的 OpenRouter API Key。
2. 在“选择生成模板”中选择“诗词赏析”。
3. 在主题输入框中填写诗名、作者或学习目标，例如：

   ```text
   请赏析苏轼《水调歌头·明月几时有》，突出逐句词注、月亮意象的变化、上下阕情绪转折，并设计一个诗句与情感作用的匹配练习。
   ```

4. 点击“实时生成 Showcase”，等待页面生成。

建议同时写清楚学习对象和重点。例如“面向初中生，解释生僻词，重点分析景物如何承载思乡情绪”，比只输入“赏析这首诗”更容易得到合适的阅读路径。

### 方式 C：上传诗词资料

如果要学习课本、讲义或一组诗词，可以点击“📚 上传资料”：

1. 上传 PDF、EPUB、DOCX、Markdown、TXT、网页、表格或图片资料。
2. 等资料状态变为“可用于生成”后勾选资料。
3. 在“学习目标”中填写要求，例如“只讲《唐诗三百首》第 12 首，先解释字词，再分析意象”。
4. 点击“用所选资料生成课程”。

扫描版资料可能需要先完成 OCR；资料库和实时生成均需要连接 API 服务。

## 二、推荐阅读流程

诗词案例建议按照页面从上到下阅读，不必一次记住所有解释。

### 1. 先读原文，再查看词注

在“原文”或“原文与微注”区域，先完整读一遍诗。带有下划线提示的词语可以悬停查看解释，例如“滟滟”“芳甸”“捣衣砧”“万里”“独登台”等。

推荐顺序是：

1. 先不看注释，感受诗的画面和语气。
2. 再查看生僻词、典故和空间词的解释。
3. 回到原句，观察词义如何改变画面或情绪。

### 2. 沿时间线理解诗的镜头变化

“时间线”不是简单的创作年代介绍，而是把诗的阅读过程拆成几个阶段。

以《春江花月夜》为例，读者会依次经历：

```text
江潮与明月升起 → 月光铺向万里 → 追问千年人生
→ 楼上人与舟中人相望 → 月光成为寄情的方向 → 月落而余情未尽
```

点击每一幕，先看该阶段的关键诗句，再留意“眼前画面”和“情绪转折”。阅读重点是观察同一个“月”如何从景物变成时间尺度，最后又变成人与人之间的联系。

### 3. 进入情境对话

“情境对话”把诗中的处境转化为两个人可以理解的交流。例如《春江花月夜》的“楼上人”和“江上人”隔江相望，用对话表现“相望不相闻”的距离感。

阅读时要注意：

- 对话是基于原诗的解释性重构，不是诗人真实说过的话。
- 先找对话对应的原句，再判断人物的语气和处境。
- 可把自己代入其中一方，思考“如果是我，会怎样解释这轮月亮”。

### 4. 完成意象匹配练习

在“把月亮放回诗里”或类似的匹配练习中，点击左侧诗句，再点击右侧对应作用，也可以直接拖拽配对。

例如：

| 诗句 | 月亮承担的作用 |
| --- | --- |
| “海上明月共潮生” | 铺开辽阔的夜景 |
| “江月年年望相似” | 映照时间与人生更替 |
| “愿逐月华流照君” | 承载跨越距离的心意 |

答错时先回看时间线，再重新判断诗句中的月亮究竟是在“写景”“写时间”，还是在“寄托情感”。

### 5. 用延伸问题完成自己的理解

页面底部的“延伸探索”适合在读完后使用。可以直接选择问题，也可以向页面编辑 Agent 提问，例如：

- 为什么《春江花月夜》写离愁，却仍然有开阔、明亮的气质？
- 《登高》前两联的宏大秋景，怎样转入后两联的个人身世之愁？
- 同一个意象在诗中有没有发生作用变化？请用原句证明。

回答时尽量采用“原句 + 画面 + 情绪/作用”的格式，而不是只写一个形容词。

## 三、页面设置建议

在“生成设置”中，可以按阅读场景调整：

- **诗意墨韵**：暖色宣纸、宋体和较大留白，适合日常精读。
- **夜读朗诵**：深色背景和夜读氛围，适合晚间阅读或朗诵展示。
- **文学杂志**：克制的长文排版，适合篇幅较长的赏析。
- **自动分页演示**：将内容排成 16:9 页面，适合课堂讲解或投屏。
- **生成并播放讲稿音频**：开启后，可为支持的生成流程生成讲稿并播放。

第一次使用建议选择“诗意墨韵”、标准页面，并保留“深度讲解、情境对话、时间线、匹配练习、延伸探索”这些组件。

## 四、如何使用页面编辑 Agent

打开案例后，点击右下角“✦ 修改案例”：

1. 选择“问答”可以针对当前页面提问。
2. 选择“编辑”并输入具体修改要求，例如“把《登高》的匹配练习改成四联与情绪变化的配对”。
3. 需要先确认方案时选择“先给方案”；确认后再执行页面修改。
4. 需要修改某个具体卡片时，先使用“选择组件”，再提交修改要求。

页面编辑 Agent 需要配置 API 服务；静态案例本身可以在没有 API Key 的情况下浏览。

## 五、一次完整的使用示例

以《春江花月夜》为例，一次 20 分钟的阅读可以这样安排：

1. **2 分钟**：不看解释，通读原文，记下最先出现的三个画面。
2. **5 分钟**：查看词注，重新阅读“江潮—明月—花林—白沙”的景物链条。
3. **4 分钟**：点击时间线，理解诗从自然远景转入人生追问，再转入相思。
4. **4 分钟**：阅读楼上人与江上人的情境对话，找出对应的原句。
5. **3 分钟**：完成月亮意象匹配练习。
6. **2 分钟**：回答一个延伸问题，并用一句原诗作为依据。

完成后，读者应能说清楚三件事：诗中写了什么画面、画面在何处发生转折、意象如何承载人物情感。

## 六、使用时的注意事项

- 内置案例是离线预生成内容，互动练习可以操作，但不会调用在线 Agent 继续生成。
- 实时生成需要后端、有效 API Key 和网络连接；如果生成失败，先检查 API 地址和 Key 配置。
- 情境对话属于文学解释，不应当当作作者原话或历史文献引用。
- 上传教材或个人资料前，应确认自己拥有相应的使用权限。
